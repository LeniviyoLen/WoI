# Web of Illusions (WoI): статичный сайт

## Как залить на GitHub Pages
1. Создай репозиторий на GitHub, загрузи туда ВСЁ содержимое этой папки (index.html должен лежать в корне).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root` → Save.
3. Через минуту сайт будет на `https://<твой-ник>.github.io/<репо>/`.

## Что где менять
- `config.js`: фон (`background: "assets/bg.jpg"`), ссылки, бонусный опыт по нику.
- `js/data.js`: навыки и монстры (собраны из «система характеристик.xlsx»).
- `js/app.js`, в начале: прирост статов по классам, 100 опыта в день, формула опыта.
- Иконки: клади в `assets/icons/`, в `index.html` замени эмодзи в кнопках на `<img src="assets/icons/....png">`.

## Важно
Сайт без сервера: данные персонажа хранятся в браузере игрока (localStorage).
С другого устройства персонажа не будет, а продвинутый игрок может подкрутить данные руками.
Для общей базы игроков нужен бэкенд (например Firebase/Supabase).
